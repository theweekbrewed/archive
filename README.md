# The Week, Brewed — the archive

The public record behind [The Week, Brewed](https://theweekbrewed.com): a calm
Sunday-morning news digest.

Every issue we publish is committed here, as published. Nothing is edited in
place. If we get something wrong, the correction is a new commit that says so,
and the original stays where it was — because a record you can quietly rewrite
is not a record.

Stay informed. Leave inspired. Sundays only.

## How we make it

We are honest about this on every issue, and we will be honest about it here.

- **Harvest.** Software reads a wide spread of public sources every week and
  clusters what more than one of them independently reported.
- **Draft.** An AI model writes the first pass, grounded in those sources. Every
  claim carries a citation, and a check refuses drafts that wander off them.
- **Edit.** A human reads every word, kills what doesn't earn its place, fixes
  what's wrong, and signs off. A person is responsible for what you read.

The machinery that does the harvesting and drafting lives in a private
repository. This one holds the output — the part that belongs to readers.

## What's in here

```
content/
  issues/       one file per published issue, exactly as it went out
  crosswords/   the weekly mini
```

Each issue file carries its own sources, so you can check us story by story
without leaving the file.

More is coming — a follow-through ledger for stories we promised to revisit, and
machine-readable provenance for how each story was chosen. When those exist,
they'll be documented here. Until then, this section says only what's true.

## Using this

The archive is meant to be forked, queried, quoted, and argued with. That's the
point of publishing it.

Licensing has two halves, and the difference matters:

- **Ours** — our editorial text, summaries, headlines, structure, metadata, and
  datasets — is licensed **[CC BY 4.0](LICENSE)**. Use it commercially, remix
  it, build on it. Just credit The Week, Brewed and link back.
- **Not ours** — quoted excerpts, headlines, and links from the news
  organizations we cite — is **not ours to license**. Those remain the property
  of their publishers, quoted briefly with attribution and a link. If you
  republish an issue, that boundary comes with it.

Suggested citation: *The Week, Brewed*, issue of YYYY-MM-DD,
`theweekbrewed.com/issue/<slug>`. See [CITATION.cff](CITATION.cff).

## This is a record, not a forum

We don't run a comment section, and this repository isn't a back door to one.
Pull requests against published issues are closed on principle: the archive's
value is that it reflects what we actually sent.

- **Found a factual error?** Email
  [hello@theweekbrewed.com](mailto:hello@theweekbrewed.com?subject=Correction).
  We'd rather be corrected than be quiet, and corrections run in the next issue
  with the original left visible.
- **Building something with the data?** We'd genuinely like to hear about it.
  Same address.
